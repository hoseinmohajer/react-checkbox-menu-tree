# react-checkbox-menu-tree

> **This package has been renamed to [`react-checktree`](https://www.npmjs.com/package/react-checktree).**

## Migration

```bash
npm uninstall react-checkbox-menu-tree
npm install react-checktree
```

Then update your imports:

```javascript
// Before
import MenuTree from "react-checkbox-menu-tree";

// After
import MenuTree from "react-checktree";
```

The API is 100% the same. This wrapper package re-exports everything from `react-checktree` for backward compatibility, but it will not receive new features.
